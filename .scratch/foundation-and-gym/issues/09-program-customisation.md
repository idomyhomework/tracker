# 09: Program customisation

**What to build:** The user tailors their Program: enables or disables Exercises, reorders them within a Program Day by drag and drop, edits target sets and reps, adds their own Exercises, opens a video tutorial search for any Exercise, and can build a Program from scratch without a template.

**Blocked by:** 04 — Choose a Program

**Status:** ready-for-agent

- [ ] Program operations (toggle, reorder, edit targets, add Exercise, create empty Program) are domain functions, tested.
- [ ] Disabled Exercises don't appear in a new Active Workout.
- [ ] User-added Exercises store the name as typed and need a MET choice from a small fixed list.
- [ ] Drag-and-drop reorder works on touch screens.
- [ ] Each Exercise has a link that opens a video tutorial search for it.
- [ ] Changes persist across reload and never affect a running Active Workout.
